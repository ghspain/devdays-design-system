Paleta

Extraída del uso real en las cajas de texto (frecuencia en el XML), no del theme1.xml — que solo trae colores de relleno de Office. Tema dark-only: negro puro y casi-negros con tinte frío, más los dos acentos de marca de Copilot.

Tipografía

El tema declara Arial/Segoe UI, pero el uso real es la pila de GitHub: Mona Sans (open-source, SIL OFL) para titulares y cuerpo, Mona Sans Mono para código. Pocos niveles y tamaños grandes. Escala detectada (pt → px @96dpi):

80px · 60ptUna idea por slide
52px · 36–40ptH1 · título de diapositiva
32px · 24ptH2 · subtítulo de sección
21px · 16ptBody grande · el caballo de batalla del deck CLI
16px · 12–14ptBody · texto de apoyo y captions
13px · 10ptMicro · etiquetas, fuentes, paginación
monoconst accent = '#5EEC83' // Mona Sans Mono

Plantilla Slidev

Implementación funcional del sistema de diseño: 6 layouts, tokens CSS, fuentes self-hosted y 7 slides de ejemplo. Ratio 16:9 (1280×720).

cover

Titular grande + halo degradado + kicker en lima.

section

Separador de capítulo con número gigante.

two-cols

Texto + captura de producto sobre panel elevado.

code

Bloque de código con caption de archivo en mono.

roadmap

Tarjetas numeradas reveladas con v-click.

quote

Statement slide de texto a pantalla completa.

# clonar y arrancar
git clone https://github.com/ghspain/devdays-design-system.git
cd devdays-design-system/slidev-template
npm install
npm run dev      # localhost:3030

# slides.md → slot sugar de Slidev v51 (ya no existe el fragmento "--")
---
layout: cover
---
# GitHub Copilot DevDays
::second::
Una idea por slide.
::second::

⚠️ Slidev v51 reescribió el sistema de fragments: usa marcadores de slot ::nombre:: (una línea completa) o <v-click>. El -- clásico se renderiza como texto literal. Detalle en slidev-template/README.md.
